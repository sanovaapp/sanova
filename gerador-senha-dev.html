🔐 Gerador de senha dev

Painel desenvolvedor do Sanova v3.6.0
O que vai acontecer:
1. Você inventa uma senha forte (mín. 16 chars)
2. Sua senha NUNCA sai do seu celular
3. Calculo o hash SHA-256 dela (impossível voltar pra senha original)
4. Você copia o hash e cola no chat com o Claude Code
5. Você salva a senha no Google Password Manager
Mistura: letras maiúsculas/minúsculas, números, símbolos. Quanto mais variado, melhor.
